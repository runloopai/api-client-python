Core Module¶

class runloop_api_client.sdk.async_.AsyncRunloopSDK(*, bearer_token=None, base_url=None, timeout=NOT_GIVEN, max_retries=5, default_headers=None, default_query=None, http_client=None, api_pool_shards=8, background_pool_shards=16, transfer_pool_shards=2)¶

High-level asynchronous entry point for the Runloop SDK.

Provides a Pythonic, object-oriented interface for managing devboxes, blueprints, snapshots, and storage objects. Exposes the generated async REST client via the api attribute for advanced use cases.

Variables:

  • api (AsyncRunloop) – Direct access to the generated async REST API client

  • agent (AsyncAgentOps) – High-level async interface for agent management.

  • axon (AsyncAxonOps) – [Beta] High-level async interface for axon management

  • benchmark (AsyncBenchmarkOps) – High-level async interface for benchmark management

  • devbox (AsyncDevboxOps) – High-level async interface for devbox management

  • blueprint (AsyncBlueprintOps) – High-level async interface for blueprint management

  • scenario (AsyncScenarioOps) – High-level async interface for scenario management

  • scorer (AsyncScorerOps) – High-level async interface for scorer management

  • snapshot (AsyncSnapshotOps) – High-level async interface for snapshot management

  • storage_object (AsyncStorageObjectOps) – High-level async interface for storage object management

  • network_policy (AsyncNetworkPolicyOps) – High-level async interface for network policy management

  • gateway_config (AsyncGatewayConfigOps) – High-level async interface for gateway config management

  • mcp_config (AsyncMcpConfigOps) – High-level async interface for MCP config management

  • secret (AsyncSecretOps) – High-level async interface for secret management

Example

>>> runloop = AsyncRunloopSDK()  # Uses RUNLOOP_API_KEY env var
>>> devbox = await runloop.devbox.create(name="my-devbox")
>>> result = await devbox.cmd.exec("echo 'hello'")
>>> print(await result.stdout())
>>> await devbox.shutdown()

class runloop_api_client.sdk.async_.AsyncBlueprintOps(client)[source]¶

High-level async manager for creating and managing blueprints.

Accessed via runloop.blueprint from AsyncRunloopSDK, provides coroutines to create Dockerfile-based blueprints, inspect build logs, and list existing blueprints.

Example

>>> runloop = AsyncRunloopSDK()
>>> blueprint = await runloop.blueprint.create(
...     name="my-blueprint",
...     dockerfile="FROM ubuntu:22.04\nRUN apt-get update",
... )
>>> blueprints = await runloop.blueprint.list()

To use a local directory as a build context, use an object.

Example

>>> from datetime import timedelta
>>> from runloop_api_client.types.blueprint_build_parameters import BuildContext
>>> runloop = AsyncRunloopSDK()
>>> obj = await runloop.object_storage.upload_from_dir(
...     "./",
...     ttl=timedelta(hours=1),
... )
>>> blueprint = await runloop.blueprint.create(
...     name="my-blueprint",
...     dockerfile="FROM ubuntu:22.04\nCOPY . .\n",
...     build_context=BuildContext(type="object", object_id=obj.id),
... )
